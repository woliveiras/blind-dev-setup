7zr.exe 26.06 - 7-Zip reduced console program (LZMA SDK)
Author: Igor Pavlov

This project downloads the unmodified x86 7zr.exe from the official 26.06
release. It is byte-identical to bin/7zr.exe in the LZMA SDK 26.06 archive.
The license section below is reproduced from DOC/lzma-sdk.txt in that SDK.
It applies to this reduced helper, not to every program in the full 7-Zip
package.

Official licensing page:
https://www.7-zip.org/sdk.html
Exact SDK source and binaries:
https://github.com/ip7z/7zip/releases/download/26.06/lzma2606.7z
